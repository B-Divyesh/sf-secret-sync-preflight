Policy / 2026-08-28

Privacy for key-name checks.

The CLI works with local key-name files. The browser sample stays in the current tab.

CLI data

The CLI reads a local manifest and key-name exports. It writes a report only when you provide --report. Reports can contain key names, so restrict access to them.

Browser demo

The demo keeps sample edits in page memory. It does not write cookies, local storage, or session storage. Refreshing or resetting discards edits.

Site operation

This site has no analytics, advertising, tracking pixels, third-party scripts, or remote fonts. The hosting platform may process ordinary request metadata for security and operations.

Your choices

Do not paste secret values into the demo. Entries such as KEY=value are rejected.

SSP/flight

Key names can be sensitive. Store reports on your CI runner. Built by Param Factory · v0.1.0
