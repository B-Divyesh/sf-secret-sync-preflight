Policy · 5 September 2026

Privacy for secret key drift checks.

The CLI uses local key-name files. The browser sample stays in the current tab.

CLI data

The CLI reads the manifest and destination exports you provide. It writes a report only when you use --report.

Reports can contain key names. Restrict access to every saved report.

Browser sample

The sample does not write cookies, local storage, session storage, or IndexedDB. Refreshing or resetting discards edits.

Site requests

The pages request files only from this site. They send no analytics or advertising requests.

The hosting platform may process ordinary request details for security and operations.

Privacy questions

Send a private report through GitHub Security Advisories (opens GitHub). Never include secret values.
