Key-name checks

Compare expected and destination keys.

Your repository lists expected keys. Each destination export lists keys that exist. The CLI compares those names without changing the files.

  1. 01

    List expected keys

    List each environment’s expected keys in a TOML file.

  2. 02

    Export destination keys

    Export one key name per line with a read-only provider command.

  3. 03

    Block unsafe deployment

    Read a terminal, JSON, or GitHub report. Unsafe results use exit code 1.

Privacy and scope

Know what the CLI does not do.

It reads the local manifest and exports you provide. It never connects to a provider or changes provider data.

  • No secret valuesLines containing values are rejected without printing the value.
  • No automatic changesThe CLI reports drift but never updates or deletes a provider secret.
  • Local reportsA report file is created only when you use --report.
